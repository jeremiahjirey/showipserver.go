# ShowIP Server

Aplikasi sederhana berbasis Golang yang menampilkan alamat IP publik server ketika diakses.

## Fitur

- Menampilkan alamat IP publik dari server.
- API dapat diakses melalui HTTP GET request.

## Persyaratan

Sebelum menjalankan aplikasi ini, pastikan Anda telah menginstal:

- [Go](https://golang.org/dl/) versi 1.15 atau lebih baru.
